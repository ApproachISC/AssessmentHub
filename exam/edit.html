How to generate your exam JSON

Follow these steps to convert your exam document into the format this platform expects.

  1. 01 Open claude.ai in a new tab and start a fresh conversation.
  2. 02 Attach your exam document (PDF or DOCX). Include your answers either in a separate file or directly within the exam document (e.g., the correct option highlighted or in bold).
  3. 03 Copy the prompt below and paste it into the same message, then send.
  4. 04 Claude will reply with a JSON file. Download the file and save it on your computer.
  5. 05 Come back here and upload the .json file. Review the questions, upload any required images, then save.

Bulk Import

Import Questions from CSV / XLSX

Import a spreadsheet of questions into a section. Supports multiple_choice, true_false, fill_blank, and short_answer only — use JSON upload or manual building for other question types.

Expected columns (first row = header): type, prompt, points, option_a, option_b, option_c, option_d, answer. For true_false, leave the option columns blank and put T or F in answer. For fill_blank, leave the option columns blank, use {blank} in the prompt, and put the correct answer in answer. For multiple_choice, answer should be the letter (a/b/c/d) of the correct option. For short_answer (manually graded), leave the option columns blank and put a reference answer in answer (optional).
